# Evidencias de Destino+

Esta carpeta está reservada para evidencias reales de la ejecución y entrega
del proyecto.

La guía completa se encuentra en:

```text
docs/pruebas/plan_evidencias.md
```

Estructura prevista:

```text
01_entorno/
02_autenticacion/
03_navegacion/
04_viajes_actividades/
05_integraciones/
06_pruebas/
07_release_android/
08_monitoreo/
```

Las subcarpetas se crearán cuando existan archivos reales que guardar.

No deben incluirse aquí:

- secretos;
- contraseñas;
- tokens;
- configuraciones privadas;
- evidencias fabricadas.

Las capturas y salidas finales deben corresponder a pruebas realmente
ejecutadas sobre la versión que se entregará.
